## [EXT] 데이터 정합성 기준

| 항목 | 기준 |
|------|------|
| 입력 데이터 검증 | 스키마 유효성 검사 필수 |
| 변환 결과 검증 | 입력 레코드 수 = 출력 레코드 수 (손실 없음) |
| Null/이상값 처리 | 명시적 처리 전략 코드에 기록 |
| 중복 제거 | 명시적 dedup 전략 존재 |

## [EXT] 스키마 마이그레이션 안전성

| 항목 | 기준 |
|------|------|
| 마이그레이션 롤백 | 모든 마이그레이션에 down 스크립트 존재 |

## [EXT] 오류 복구 기준

- 중단 가능한 처리: 체크포인트 저장 필수 (재시작 가능)
- 부분 실패: 실패 레코드 별도 로그 + 재처리 수단 제공
- 조용한 실패 절대 금지 (BASE §4 동일 적용, 데이터 툴에서 특히 중요)
