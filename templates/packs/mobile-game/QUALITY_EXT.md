# QUALITY_EXT.md — mobile-game 품질 확장

> 이 파일의 내용은 프로젝트 `QUALITY_SCORE.md`의 `## Pack Extensions` 섹션에 병합한다.
> BASE 기준에 추가되는 게임 특화 항목만 포함한다.

## [EXT] 테스트 추가 기준

BASE §3에 아래 항목 추가:

- **핵심 파일** (CLAUDE.md에 목록 명시): 테스트 없이 수정 불가, 각 파일마다 테스트 1개 이상
- **HUD/오버레이**: 상태 반응성 테스트 필수 (지정된 핵심 파일 포함)
- **스테이지 JSON**: 스키마 검증 100%

## [EXT] 스테이지/콘텐츠 검증 기준

*(스테이지 기반 게임에만 해당. 없으면 삭제)*

| 항목 | 기준 |
|------|------|

## [EXT] 게임 플레이 품질

| 항목 | 기준 | 측정 |
|------|------|------|

| 물리 정확도 | 기대 동작과 일치 | 수동 확인 |

## [EXT] 출시 전 최종 체크리스트

```
기능 완성도:
  □ 전체 스테이지/콘텐츠 클리어 가능 검증
  □ 핵심 아이템/시스템 정상 작동
  □ 저장/로드 정상 작동
  □ 튜토리얼 정상 작동

디바이스 호환성 (Mobile):
  □ 최소 지원 OS 버전 정상 작동
  □ 최소 해상도 정상 작동
  □ 노치/펀치홀 Safe Area 처리

스토어 제출:
  □ 앱 크래시율 0% (내부 테스트)
  □ 앱 용량 [N]MB 이하
  □ 개인정보처리방침 URL 유효
```
