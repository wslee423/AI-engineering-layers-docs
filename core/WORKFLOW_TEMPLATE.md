# WORKFLOW_TEMPLATE.md — 작업 흐름 메타 가이드

> Core Layer 문서. 프로젝트의 `WORKFLOW.md` 작성을 위한 가이드.
> 실제 작업 흐름 기준은 `templates/base/WORKFLOW.md`를 복사해 사용한다.

---

## 목적

`WORKFLOW.md`는 사람-에이전트 반복 실행 루프를 정의한다.
모든 에이전트가 세션 시작/종료 시 이 문서를 따른다.

---

## 필수 섹션

| 섹션 | 내용 | 필수 여부 |
|------|------|----------|
| 세 가지 루프 | Level 1/2/3 루프 정의 | ✅ |
| 세션 시작 루틴 | 에이전트 세션 시작 체크리스트 | ✅ |
| 기능 크기 분류 | Small/Large 판단 기준 | ✅ |
| 기능 루프 | Small/Large 흐름 정의 | ✅ |
| 에스컬레이션 조건 | 즉시 멈추는 조건 목록 | ✅ |
| 세션 종료 루틴 | 핸드오프 형식 포함 | ✅ |
| Phase 루프 | 진입/완료 조건 | 프로젝트에 따라 |

---

## 커스터마이징 포인트

- **세션 시작 루틴**: 읽어야 할 프로젝트 특화 문서 추가 가능
- **기능 크기 기준**: 팀 상황에 맞게 Small/Large 기준 조정 가능
- **에스컬레이션**: 프로젝트별 추가 조건 삽입 가능

---

## 불변 요소 (변경 금지)

- 에스컬레이션 조건 목록 삭제 금지
- 큰 기능 사람 최종 승인 제거 금지
- 세션 종료 루틴 (`NEXT_SESSION.md` 핸드오프) 생략 금지

---
