## 8. Game 특화: 출시 전 최종 체크리스트

```
기능 완성도:
  □ 전체 스테이지/콘텐츠 클리어 가능 검증
  □ 핵심 아이템/시스템 정상 작동
  □ 저장/로드 정상 작동
  □ 튜토리얼 정상 작동

디바이스 호환성 (Mobile):
  □ 최소 지원 OS 버전 정상 작동
  □ 최소 해상도 정상 작동
  □ 일반 해상도 정상 작동
  □ 노치/펀치홀 Safe Area 처리

스토어 제출:
  □ 앱 크래시율 0% (내부 테스트)
  □ 앱 용량 [N]MB 이하
  □ 개인정보처리방침 URL 유효
```

## 9. 검증 체크리스트 (기능 완료 시)

**Reviewer subagent가 순서대로 실행한다. 각 항목을 실제 명령어로 확인.**

```
Step 1: 정적 분석
  □ analyze 경고 0건

Step 2: 테스트
  □ 전체 테스트 통과
  □ 핵심 파일 각각 테스트 존재
  □ 새 HUD/오버레이 상태 반응성 테스트 존재

Step 3: 성능
  □ fps 목표 달성 (수동 또는 자동 측정)
  □ 메모리 누수 없음

Step 4: 스테이지 검증 (해당 시)
  □ JSON 스키마 유효성
  □ 클리어 가능 여부
  □ 오브젝트 수 범위
  □ 드롭률 기준

Step 5: 안정성
  □ 저장 실패 시 복구 동작 확인
  □ 엣지 케이스 (게임 오브젝트 예외 상황)

Step 6: 스펙 일치
  □ 변경 내용이 product-specs와 일치
  □ 스펙에 없는 기능 추가 없음
```
