## 4. 에이전트 행동 규칙

### 결정 필요 항목을 만났을 때
| 상황 | 행동 |
|------|------|
| 자율 범위 내 판단 가능 | 진행 + 완료 보고에 포함 |
| 판단 기준 명확 (다른 문서에서 추론 가능) | 진행 + 이 파일에 기록 |
| 불명확 | 멈추고 에스컬레이션 + 이 파일에 등록 |
| 🔴 Blocker 접촉 | 즉시 중단 + 에스컬레이션 + 이 파일에 등록 |

### 결정 반영 시
1. 결정 내용을 해당 항목에 기록 → 상태 `결정됨`
2. 반영 체크리스트 수행
3. 모두 완료 → 상태 `반영 완료` + 섹션 5로 이동
